# Trademark and naming policy

The source code in this repository is licensed under the GNU General Public License,
version 3 or later (see `LICENSE`). That licence covers the code. It does not grant any
right to the project's **name** or **visual identity**.

## What is reserved

- The name **"Rún"** (and "Run" when used to refer to this app), the app-store listing
  names, and the bundle and package identifiers `com.vg.run`.
- The **app icon** and the **runestone artwork** used in the app, the stores and this
  repository (see `LICENSE-ART`).

These identify the builds that the maintainer publishes. People who install "Rún" from the
App Store or Google Play must be able to trust that it is this code, built and signed by
this project, and reaching this project's relay.

## What you may do

- Build the code for yourself and run it, under any name, including no name.
- Fork the code and publish your fork under the GPL, **with a different name and a
  different icon**, and without the runestone artwork.
- Say that your fork is "based on Rún" or "derived from Rún", as a factual statement.
- Use the name in reviews, articles, comparisons, bug reports and academic work.

## What you may not do

- Distribute a modified build, or a build pointed at a different relay, under the name
  "Rún" or with its icon, on an app store, a website or a package repository.
- Use the name or icon in a way that suggests the maintainer endorses or operates your
  build or your relay.
- Register "Rún" or confusingly similar names or icons for a messaging app.

## Why

A messenger's security claims are only as good as the binary you actually run. If builds
that behave differently carried the same name and icon, users could not tell them apart.
This policy exists to keep that distinction, not to restrict what you do with the code.
